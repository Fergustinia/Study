# Scrum PM — система управления проектами с метриками Agile

Сайт для выпускной работы: управление проектами с поддержкой Agile/Scrum и встроенным анализом Scrum-метрик.

- **Фронтенд:** React (Vite). Режим по умолчанию — данные в **localStorage**.
- **Сервер (раздел 4.1):** REST API на Node.js (Express), JWT-аутентификация, SQLite, расчёт метрик на сервере.

## Запуск фронтенда

```bash
npm install
npm run dev
```

Откройте в браузере адрес из вывода (обычно `http://localhost:5173`).

Сборка: `npm run build`. Превью: `npm run preview`.

## Запуск серверной части (4.1)

```bash
cd server
npm install
npm run dev
```

API: `http://localhost:3001`. Описание эндпойнтов и примеры — в `server/README.md`.

## Возможности фронтенда

- **Дашборд** — сводка по проектам, спринтам, задачам и прогрессу (SP); лента активности по проекту (при работе через API).
- **Проекты** — создание, редактирование и удаление проектов.
- **Спринты** — создание спринтов с датами и целью по выбранному проекту.
- **Канбан-доска** — колонки «Бэклог», «К выполнению», «В работе», «Готово»; перетаскивание задач; приоритет, тип и **исполнитель**; фильтры; **комментарии** к задаче в модалке.
- **Метрики** — Velocity, Burndown, Cycle time, **Lead time**, прогресс спринтов, сводка по типу задачи; **экспорт отчёта в CSV**.
- **Уведомления** (при API) — колокольчик в шапке: назначение на задачу и др.
- **Поиск** — глобальный поиск по проектам и задачам в шапке (переход на доску).
- **Профиль** — имя, email, выход из аккаунта (локальный режим без пароля).

В режиме без сервера данные хранятся в браузере (localStorage).

## Аккаунт на сервере

Чтобы вход и профиль работали через API (JWT, пароль):

1. Запустите сервер: `cd server && npm run dev`
2. В корне проекта создайте файл `.env` и укажите: `VITE_API_URL=http://localhost:3001`
3. Перезапустите фронтенд: `npm run dev`

На странице входа появится форма **Войти** (имя или email + пароль) и **Регистрация** (имя, email, пароль). Профиль сохраняется на сервере через `PATCH /api/auth/profile`.
