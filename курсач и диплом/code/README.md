# Scrum PM — система управления проектами с метриками Agile

Сайт для выпускной работы: управление проектами с поддержкой Agile/Scrum и встроенным анализом Scrum-метрик. Собран на **React** (Vite). Данные хранятся в **localStorage** (без базы данных).

## Запуск

```bash
npm install
npm run dev
```

Откройте в браузере адрес из вывода (обычно `http://localhost:5173`).

Сборка для продакшена: `npm run build`. Превью сборки: `npm run preview`.

## Возможности

- **Дашборд** — сводка по проектам, спринтам, задачам и прогрессу (SP).
- **Проекты** — создание, редактирование и удаление проектов.
- **Спринты** — создание спринтов с датами и целью по выбранному проекту.
- **Канбан-доска** — колонки «Бэклог», «К выполнению», «В работе», «Готово»; перетаскивание задач; перенос из бэклога в спринт и обратно.
- **Метрики** — Velocity (завершённые SP по спринтам), Burndown по выбранному спринту, прогресс спринтов по задачам и SP.

Данные сохраняются в браузере и остаются после перезагрузки страницы.
